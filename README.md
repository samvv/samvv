Welcome to my place on GitHub!

I'm a software developer with a particular interest in programming language design, compilers and formal systems.

My dream is to one day improve the web with a statically typed, compiled and very performant programming language. The current iteration of that dream is called [Bolt](https://github.com/boltlang/bolt). It can already type-check simple programs, but there is still a long way to go.

My latest adventures are with [Infera](https://github.com/samvv/infera), a collection of tools for analysing and working in formal systems. I'm hoping to transform it to a full-blown theorem prover over time. It might also help me with studying mathemathics, and thus indirectly improve Bolt.

Feel free to look around!
