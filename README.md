## Welcome to my place on GitHub!

I'm a software developer with a particular interest in programming language design, compilers and formal systems.

My dream is to one day improve the web with a statically typed, compiled and very performant programming language. The current iteration of that dream is called [Bolt](https://github.com/boltlang/bolt). It can already compile simple programs, but there is still a long way to go.

Feel free to look around!
